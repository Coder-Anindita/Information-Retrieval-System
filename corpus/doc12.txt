The vector space model represents documents and queries as vectors in a high-dimensional space. Each dimension corresponds to a term in the vocabulary, and the value is the weight of that term in the document. The similarity between a query and a document is usually measured using cosine similarity, which compares the angle between their vectors. Documents with vectors pointing in a similar direction to the query are considered more relevant. Unlike Boolean retrieval, the vector space model produces a ranked list of results. It also allows partial matching, so documents need not contain every query term.
