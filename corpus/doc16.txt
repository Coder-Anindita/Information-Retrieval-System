Web crawlers are programs that automatically download pages by following hyperlinks from one website to another. A crawler starts with a set of seed URLs, fetches those pages, extracts their links and adds new URLs to a queue called the frontier. Crawlers must be polite, which means respecting the robots.txt file and not overloading web servers with requests. They also need to detect duplicate pages and avoid crawler traps that generate endless links. Because the web keeps changing, crawlers revisit pages regularly to keep the index fresh. Large search engines run distributed crawlers that fetch billions of pages.
