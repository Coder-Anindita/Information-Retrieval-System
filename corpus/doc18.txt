A permuterm index or k-gram index can be used to answer wildcard queries efficiently. In a permuterm index, every rotation of a term with an end marker is stored, so any wildcard query can be turned into a prefix lookup. The k-gram index instead breaks every term into overlapping sequences of k characters, such as bigrams or trigrams. To answer a wildcard query, the system finds the k-grams in the pattern and intersects their term lists. Because k-gram matching can produce false positives, a final post-filtering step checks each candidate against the original pattern. The k-gram index uses much less space than the permuterm index.
