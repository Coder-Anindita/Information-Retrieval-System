Database systems store structured data in tables with rows, columns and fixed schemas. They are queried using languages like SQL, which return exact matches based on precise conditions. Retrieval systems, on the other hand, handle unstructured text documents where there is no fixed format. In a database, a query either matches a record or does not, while retrieval systems rank documents by how relevant they are. Many modern applications combine both approaches, for example an online shop that filters products by price and searches their descriptions by keywords. Some databases now include full-text search features built on inverted indexes.
